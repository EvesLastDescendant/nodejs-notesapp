# Terminal-Based Notes App

A simple terminal-based notes application built using `yargs`, `chalk`, and the `fs` libraries. This app allows users to create, read, update, and delete notes from the command line.

## Features

- Create new notes
- Read existing notes
- Update notes
- Delete notes

## Dependencies

- [yargs](https://www.npmjs.com/package/yargs) - A library for building interactive command-line tools.
- [chalk](https://www.npmjs.com/package/chalk) - A library for styling terminal string output.
- [fs](https://nodejs.org/api/fs.html) - Node.js file system module for reading and writing files.

## Installation

1. Clone the repository or download the source code:
   ```bash
   git clone <repository-url>

2. Navigate to the project directory:
   ```bash
   cd <project-directory>

3. Install dependencies:
   ```bash
   npm install

## Usage
To run the app, navigate to the project directory and run:
   ```bash
   node app.js
